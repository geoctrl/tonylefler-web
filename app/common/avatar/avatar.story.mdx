# Avatar

A user representation component that displays a profile image with graceful fallbacks to initials or an icon.

## Import

```tsx
import { Avatar } from "root";
```

## Basic Usage

<Example>
  <div className="flex gap-3 items-center">
    <Avatar name="Alice Johnson" />
    <Avatar name="Bob Smith" />
    <Avatar name="Carol White" />
  </div>
</Example>

```tsx
<Avatar name="Alice Johnson" />
<Avatar name="Bob Smith" />
<Avatar name="Carol White" />
```

## With Image

Provide a `src` URL to display a profile photo. If the image fails to load, the avatar falls back to initials or icon automatically.

<Example>
  <div className="flex gap-3 items-center">
    <Avatar
      src="https://i.pravatar.cc/150?img=1"
      alt="Jane Doe"
      name="Jane Doe"
    />
    <Avatar
      src="https://i.pravatar.cc/150?img=2"
      alt="Mark Taylor"
      name="Mark Taylor"
    />
    <Avatar
      src="https://i.pravatar.cc/150?img=3"
      alt="Sarah Chen"
      name="Sarah Chen"
    />
  </div>
</Example>

```tsx
<Avatar
  src="https://i.pravatar.cc/150?img=1"
  alt="Jane Doe"
  name="Jane Doe"
/>
```

## Initials Fallback

When no `src` is provided (or the image fails to load), the avatar shows initials derived from the `name` prop. Two initials are shown for multi-word names (first and last).

<Example>
  <div className="flex gap-3 items-center">
    <Avatar name="Alice Johnson" />
    <Avatar name="Bob Smith" />
    <Avatar name="Carol White" />
    <Avatar name="David" />
    <Avatar name="Emma Rose Taylor" />
  </div>
</Example>

```tsx
<Avatar name="Alice Johnson" />   {/* → AJ */}
<Avatar name="Bob Smith" />       {/* → BS */}
<Avatar name="David" />           {/* → D  */}
<Avatar name="Emma Rose Taylor" /> {/* → ET */}
```

## Accessibility

- The `<Avatar>` renders as a `<span>` with `role="img"`.
- The accessible label is taken from `alt` if provided, then `name`, and defaults to `"Avatar"`.
- Inner fallback content (initials, icon) uses `aria-hidden="true"` to avoid double-reading by screen readers.
- Always provide a meaningful `alt` or `name` so assistive technology can identify the user.

```tsx
{/* Preferred — descriptive label */}
<Avatar src="..." alt="Jane Doe" name="Jane Doe" />

{/* Acceptable — name used as label */}
<Avatar name="Jane Doe" />

{/* When anonymous, override the label */}
<Avatar aria-label="Anonymous user" />
```
