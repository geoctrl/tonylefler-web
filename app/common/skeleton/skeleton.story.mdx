# Skeleton

A loading placeholder that mimics the shape of content while it loads, reducing perceived wait time.

## Import

```tsx
import { Skeleton } from "root";
```

## Basic Usage

<Example>
  <div className="space-y-2 w-64">
    <Skeleton variant="text" />
    <Skeleton variant="text" width="80%" />
    <Skeleton variant="text" width="60%" />
  </div>
</Example>

```tsx
<Skeleton variant="text" />
<Skeleton variant="text" width="80%" />
<Skeleton variant="text" width="60%" />
```

## Variant

### `variant="rectangular"`

The default shape. Use for images, cards, buttons, and block-level content.

- **When to use:** Placeholder for images, cards, banners, or any rectangular UI element.

<Example>
  <div className="space-y-3">
    <Skeleton variant="rectangular" width="100%" height={160} />
    <Skeleton variant="rectangular" width={120} height={36} />
  </div>
</Example>

```tsx
<Skeleton variant="rectangular" width="100%" height={160} />
<Skeleton variant="rectangular" width={120} height={36} />
```

### `variant="text"`

Sized to a single line of text (`height: 1em`). Stack multiple rows to simulate a paragraph.

- **When to use:** Placeholder for headings, labels, descriptions, or paragraph text.

<Example>
  <div className="space-y-2 w-72">
    <Skeleton variant="text" className="text-xl" />
    <Skeleton variant="text" />
    <Skeleton variant="text" width="85%" />
    <Skeleton variant="text" width="70%" />
  </div>
</Example>

```tsx
{/* Heading */}
<Skeleton variant="text" className="text-xl" />

{/* Paragraph lines */}
<Skeleton variant="text" />
<Skeleton variant="text" width="85%" />
<Skeleton variant="text" width="70%" />
```

### `variant="circular"`

Forces equal width and height producing a perfect circle. Suitable for avatars and icon placeholders.

- **When to use:** Placeholder for user avatars, circular icons, or status indicators.

<Example>
  <div className="flex gap-4 items-center">
    <Skeleton variant="circular" width={32} height={32} />
    <Skeleton variant="circular" width={40} height={40} />
    <Skeleton variant="circular" width={48} height={48} />
    <Skeleton variant="circular" width={64} height={64} />
  </div>
</Example>

```tsx
<Skeleton variant="circular" width={32} height={32} />
<Skeleton variant="circular" width={40} height={40} />
<Skeleton variant="circular" width={48} height={48} />
<Skeleton variant="circular" width={64} height={64} />
```

## Animation

### `animation="pulse"` (default)

The element fades in and out using Tailwind's `animate-pulse`. Works well for most loading states.

<Example>
  <Skeleton variant="rectangular" width="100%" height={80} animation="pulse" />
</Example>

```tsx
<Skeleton variant="rectangular" width="100%" height={80} animation="pulse" />
```

### `animation="none"`

No animation. Use when reduced motion is preferred or when showing a stable placeholder.

<Example>
  <Skeleton variant="rectangular" width="100%" height={80} animation="none" />
</Example>

```tsx
<Skeleton variant="rectangular" width="100%" height={80} animation="none" />
```

## Accessibility

Skeleton uses `aria-hidden="true"` and `role="status"` so screen readers are informed there is a loading state without announcing decorative placeholder shapes. Pair Skeleton with an accessible loading message when announcing the loading state is important:

```tsx
<div>
  <span className="sr-only" role="status">Loading profile...</span>
  <Skeleton variant="circular" width={40} height={40} aria-hidden="true" />
</div>
```

Skeletons honor the user's reduced-motion preference when you set `animation="none"`:

```tsx
<Skeleton
  variant="rectangular"
  width="100%"
  height={80}
  animation={prefersReducedMotion ? "none" : "pulse"}
/>
```
