# Card

A surface container for grouping related content with consistent border, shadow, and padding treatment.

## Import

```tsx
import { Card, CardHeader, CardBody, CardFooter } from "root";
```

## Basic Usage

<Example>
  <Card className="w-80">
    <CardHeader>
      <span className="font-semibold text-grey-900 dark:text-grey-100">Account Settings</span>
    </CardHeader>
    <CardBody>
      <p className="text-grey-700 dark:text-grey-300 text-sm">Manage your account preferences and security settings.</p>
    </CardBody>
    <CardFooter>
      <Button intent="primary" formSize="sm">Save Changes</Button>
    </CardFooter>
  </Card>
</Example>

```tsx
<Card>
  <CardHeader>
    <span className="font-semibold">Account Settings</span>
  </CardHeader>
  <CardBody>
    <p>Manage your account preferences and security settings.</p>
  </CardBody>
  <CardFooter>
    <Button intent="primary" formSize="sm">Save Changes</Button>
  </CardFooter>
</Card>
```

## Props

### `<Card>`

`<Card>` accepts all [HTML div attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/div#attributes) and the following:

<PropsTable props={[
  {
    name: "variant",
    type: '"elevated" | "outlined" | "filled"',
    description: "Visual style of the card surface",
    default: '"elevated"',
    required: false,
  },
]} />

### `<CardBody>`

`<CardBody>` accepts all [HTML div attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/div#attributes) and the following:

<PropsTable props={[
  {
    name: "padding",
    type: '"none" | "sm" | "md" | "lg"',
    description: "Internal padding of the card body",
    default: '"md"',
    required: false,
  },
]} />

### `<CardHeader>` and `<CardFooter>`

Both accept all [HTML div attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/div#attributes). They include a border separator and consistent horizontal padding by default.

## Variant

### `variant="elevated"` (default)

A white card with a shadow. Use for primary content surfaces that need to stand out from the page background.

- **When to use:** Dashboard widgets, detail panels, primary content blocks.

<Example>
  <Card variant="elevated" className="w-80">
    <CardBody>
      <p className="text-grey-700 dark:text-grey-300 text-sm">This card uses a shadow to lift above the background.</p>
    </CardBody>
  </Card>
</Example>

```tsx
<Card variant="elevated">
  <CardBody>
    <p>This card uses a shadow to lift above the background.</p>
  </CardBody>
</Card>
```

### `variant="outlined"`

A card with a visible border and no shadow. Use when you want clear separation without depth.

- **When to use:** Lists of items, comparison tables, secondary content areas.

<Example>
  <Card variant="outlined" className="w-80">
    <CardBody>
      <p className="text-grey-700 dark:text-grey-300 text-sm">This card uses a border instead of a shadow.</p>
    </CardBody>
  </Card>
</Example>

```tsx
<Card variant="outlined">
  <CardBody>
    <p>This card uses a border instead of a shadow.</p>
  </CardBody>
</Card>
```

### `variant="filled"`

A card with a muted background fill and no border or shadow. Use for subtle grouping inside another surface.

- **When to use:** Nested content blocks, sidebar sections, inline callouts.

<Example>
  <Card variant="filled" className="w-80">
    <CardBody>
      <p className="text-grey-700 dark:text-grey-300 text-sm">This card uses a filled background for subtle grouping.</p>
    </CardBody>
  </Card>
</Example>

```tsx
<Card variant="filled">
  <CardBody>
    <p>This card uses a filled background for subtle grouping.</p>
  </CardBody>
</Card>
```

## CardBody Padding

Control the internal spacing of the card body with the `padding` prop.

<Example>

## With Header and Footer

Use `CardHeader` and `CardFooter` to add titled sections and action areas with automatic border separators.

<Example>
  <Card className="w-80">
    <CardHeader>
      <div className="flex items-center gap-2">
        <Icon name="user" className="size-4 text-grey-600 dark:text-grey-400" />
        <span className="font-semibold text-grey-900 dark:text-grey-100">User Profile</span>
      </div>
    </CardHeader>
    <CardBody>
      <p className="text-sm text-grey-700 dark:text-grey-300">Update your personal information and how it appears across the platform.</p>
    </CardBody>
    <CardFooter className="gap-2">
      <Button intent="primary" formSize="sm">Save Changes</Button>
      <Button intent="secondary" formSize="sm">Cancel</Button>
    </CardFooter>
  </Card>
</Example>

```tsx
<Card>
  <CardHeader>
    <div className="flex items-center gap-2">
      <Icon name="user" className="size-4" />
      <span className="font-semibold">User Profile</span>
    </div>
  </CardHeader>
  <CardBody>
    <p>Update your personal information...</p>
  </CardBody>
  <CardFooter className="gap-2">
    <Button intent="primary" formSize="sm">Save Changes</Button>
    <Button intent="secondary" formSize="sm">Cancel</Button>
  </CardFooter>
</Card>
```
