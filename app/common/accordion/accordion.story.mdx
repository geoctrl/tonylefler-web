# Accordion

A vertically stacked set of collapsible sections. Each section has a trigger header and a content area that expands and collapses with a smooth animation.

## Import

```tsx
import { Accordion, AccordionItem, AccordionTrigger, AccordionContent } from "root";
```

### `<AccordionTrigger>`

`<AccordionTrigger>` accepts all HTML `<button>` attributes. It automatically receives `aria-expanded` and `aria-controls` attributes.

### `<AccordionContent>`

`<AccordionContent>` accepts all HTML `<div>` attributes. It automatically receives `id`, `role="region"`, and `aria-labelledby` attributes.

## Type

### `type="single"` (default)

Only one item can be open at a time. Opening a new item closes the previously open one. Use for FAQ lists, help sections, or navigation panels.

## Controlled

Use `value` and `onValueChange` to manage open state from your own code.

export function ControlledExample() {
  const [openItem, setOpenItem] = useState("");
  return (
    <div className="space-y-3">
      <div className="flex gap-2">
        <button
          type="button"
          onClick={() => setOpenItem("step-1")}
          className="rounded-md border border-grey-900/20 dark:border-grey-100/20 px-3 py-1.5 text-sm text-grey-700 dark:text-grey-300 hover:bg-grey-900/5 dark:hover:bg-grey-100/5 transition-colors"
        >
          Open Step 1
        </button>
        <button
          type="button"
          onClick={() => setOpenItem("step-2")}
          className="rounded-md border border-grey-900/20 dark:border-grey-100/20 px-3 py-1.5 text-sm text-grey-700 dark:text-grey-300 hover:bg-grey-900/5 dark:hover:bg-grey-100/5 transition-colors"
        >
          Open Step 2
        </button>
        <button
          type="button"
          onClick={() => setOpenItem("")}
          className="rounded-md border border-grey-900/20 dark:border-grey-100/20 px-3 py-1.5 text-sm text-grey-700 dark:text-grey-300 hover:bg-grey-900/5 dark:hover:bg-grey-100/5 transition-colors"
        >
          Close All
        </button>
      </div>
      <Accordion value={openItem} onValueChange={(v) => setOpenItem(v)}>
        <AccordionItem value="step-1">
          <AccordionTrigger>Step 1: Choose a plan</AccordionTrigger>
          <AccordionContent>
            Select the plan that fits your team size. You can upgrade or downgrade at any time from your billing settings.
          </AccordionContent>
        </AccordionItem>
        <AccordionItem value="step-2">
          <AccordionTrigger>Step 2: Add team members</AccordionTrigger>
          <AccordionContent>
            Invite collaborators by email. Team members receive an invitation link valid for 48 hours.
          </AccordionContent>
        </AccordionItem>
      </Accordion>
    </div>
  );
}

## When to Use

**Use an Accordion when:**
- Content can be grouped into distinct, labeled sections
- Users typically need only one or two sections at a time (reducing visual noise)
- You need to conserve vertical space on long pages
- Presenting FAQ lists, settings panels, or step-by-step guides

**Prefer visible content when:**
- Users frequently need all sections simultaneously
- The content of each section is very short (one or two lines)
- SEO requires all content to be visible to crawlers

## Accessibility

The Accordion is built to meet [WAI-ARIA Accordion pattern](https://www.w3.org/WAI/ARIA/apg/patterns/accordion/) requirements:

- Each trigger is a `<button>` element with `aria-expanded` reflecting open state
- Each trigger has `aria-controls` pointing to the content region's `id`
- Each content region has `role="region"` and `aria-labelledby` pointing to its trigger
- Keyboard interaction: `Tab` to move focus between triggers; `Enter` or `Space` to toggle

```tsx
// The rendered HTML structure (simplified):
<div> {/* Accordion root */}
  <div> {/* AccordionItem */}
    <button aria-expanded="true" aria-controls="content-id">
      Trigger label
    </button>
    <div id="content-id" role="region" aria-labelledby="trigger-id">
      Content
    </div>
  </div>
</div>
```
