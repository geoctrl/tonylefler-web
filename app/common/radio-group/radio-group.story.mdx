# Radio Group

A group of radio inputs that allows a user to select exactly one option from a set.

## Import

```tsx
import { RadioGroup, Radio } from "root";
```

## Basic Usage

export function BasicRadioGroup() {
  const [value, setValue] = useState("option-a");
  return (
    <RadioGroup name="basic" value={value} onChange={setValue}>
      <Radio value="option-a" label="Option A" />
      <Radio value="option-b" label="Option B" />
      <Radio value="option-c" label="Option C" />
    </RadioGroup>
  );
}

## Using options Prop

Pass an array of options instead of composing Radio children manually. Each option can include an optional `description` and `disabled` flag.

export function OptionsRadioGroup() {
  const [plan, setPlan] = useState("monthly");
  return (
    <RadioGroup
      name="plan"
      value={plan}
      onChange={setPlan}
      options={[
        { value: "monthly", label: "Monthly billing", description: "Billed every month, cancel anytime." },
        { value: "annual", label: "Annual billing", description: "Save 20% with yearly billing." },
        { value: "enterprise", label: "Enterprise", description: "Custom pricing for large teams.", disabled: true },
      ]}
    />
  );
}

Passing `disabled` to the `RadioGroup` disables all options at once.

      <Radio value="overnight" label="Overnight" />

## Accessibility

- The group container has `role="radiogroup"` for screen reader identification.
- Individual radio inputs use native `<input type="radio">` for full keyboard support.
- All radios share the same `name` attribute so the browser handles single-selection semantics natively.
- Use `aria-label` or `aria-labelledby` on `RadioGroup` when there is no visible heading for the group.
- Keyboard navigation: `Tab` to focus the group, `Arrow` keys to move between options within the group.
- Disabled options are announced as disabled by screen readers.
- Focus rings are clearly visible in both light and dark mode.

## When to Use

**Use RadioGroup when:**
- Users must choose exactly one option from a small set (2–7 options).
- All options need to be visible at a glance.
- The choice is mutually exclusive.

**Don't use RadioGroup when:**
- Multiple selections are allowed (use `Checkbox` instead).
- There are many options that would clutter the layout (use a `Select` dropdown instead).
- The choice is a simple on/off toggle (use `Toggle` instead).
