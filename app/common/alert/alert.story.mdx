# Alert

A contextual feedback message that communicates status, warnings, errors, or informational notices to the user.

## Import

```tsx
import { Alert } from "root";
```

## Basic Usage

<Example>
  <div className="flex flex-col gap-3">
    <Alert intent="info">Your session will expire in 15 minutes.</Alert>
    <Alert intent="success">Your changes have been saved successfully.</Alert>
    <Alert intent="warning">Your subscription expires in 3 days.</Alert>
    <Alert intent="error">Unable to process payment. Please try again.</Alert>
  </div>
</Example>

```tsx
<Alert intent="info">Your session will expire in 15 minutes.</Alert>
<Alert intent="success">Your changes have been saved successfully.</Alert>
<Alert intent="warning">Your subscription expires in 3 days.</Alert>
<Alert intent="error">Unable to process payment. Please try again.</Alert>
```

## Intent

Each intent carries semantic meaning and is styled with an appropriate color scheme.

### `intent="info"` (default)

Neutral informational messages that do not require immediate action.

- **When to use:** Tips, hints, general notices, or secondary contextual information.
- **ARIA:** Renders with `role="status"` and `aria-live="polite"`.

<Example>
  <Alert intent="info">
    You can export your data at any time from the account settings page.
  </Alert>
</Example>

```tsx
<Alert intent="info">
  You can export your data at any time from the account settings page.
</Alert>
```

### `intent="success"`

Positive feedback confirming a completed action.

- **When to use:** After form submissions, completed uploads, successful operations.
- **ARIA:** Renders with `role="status"` and `aria-live="polite"`.

<Example>
  <Alert intent="success">
    Your profile has been updated successfully.
  </Alert>
</Example>

```tsx
<Alert intent="success">
  Your profile has been updated successfully.
</Alert>
```

### `intent="warning"`

Cautionary messages that may require user attention.

- **When to use:** Approaching limits, potential data loss, deprecated features, or actions that are reversible but consequential.
- **ARIA:** Renders with `role="alert"` and `aria-live="assertive"`.

<Example>
  <Alert intent="warning">
    Deleting this project will also remove all associated files. This action can be undone within 30 days.
  </Alert>
</Example>

```tsx
<Alert intent="warning">
  Deleting this project will also remove all associated files. This action can be undone within 30 days.
</Alert>
```

### `intent="error"`

Critical errors that require immediate attention or block progress.

- **When to use:** Validation failures, server errors, failed operations, or destructive conditions.
- **ARIA:** Renders with `role="alert"` and `aria-live="assertive"`.

<Example>
  <Alert intent="error">
    We could not verify your email address. Please check your inbox and try again.
  </Alert>
</Example>

```tsx
<Alert intent="error">
  We could not verify your email address. Please check your inbox and try again.
</Alert>
```

## Dismissible

Provide an `onDismiss` callback to render a dismiss button in the top-right corner.

<Example>
  <div className="flex flex-col gap-3">
    <Alert intent="info" title="New Feature Available" onDismiss={() => {}}>
      Try the new dashboard layout. You can switch back at any time from settings.
    </Alert>
    <Alert intent="success" onDismiss={() => {}}>
      Report generated and downloaded to your device.
    </Alert>
    <Alert intent="warning" title="Action Required" onDismiss={() => {}}>
      Your API key expires in 7 days. Rotate it to avoid service interruption.
    </Alert>
    <Alert intent="error" title="Sync Error" onDismiss={() => {}}>
      Changes could not be synced. Check your connection and try again.
    </Alert>
  </div>
</Example>

```tsx
<Alert intent="info" title="New Feature Available" onDismiss={() => setVisible(false)}>
  Try the new dashboard layout. You can switch back at any time from settings.
</Alert>

<Alert intent="success" onDismiss={() => setVisible(false)}>
  Report generated and downloaded to your device.
</Alert>
```

## Accessibility

- `intent="info"` and `intent="success"` render with `role="status"` and `aria-live="polite"`, allowing assistive technology to announce the message at a natural break.
- `intent="warning"` and `intent="error"` render with `role="alert"` and `aria-live="assertive"`, interrupting assistive technology immediately to convey urgency.
- The dismiss button includes an `aria-label="Dismiss"` for screen reader clarity.
- The icon is marked `aria-hidden="true"` since it is decorative.
